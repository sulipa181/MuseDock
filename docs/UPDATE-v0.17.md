# MuseDock v0.17 更新說明

- 發布日期：2026-11-27
- 適用對象：已經在用 MuseDock 的人（不需要懂程式碼）
- 版本：`0.16` → `0.17`
- **不需要重新登入**，帳號清單與登入態都不動，換掉 `.app` 就好

---

## 一句話

**「在 1 號選字複製、切到 2 號 `⌘V` 貼不上」這件事，這次真的修完了。**

v0.16 修的是「按鍵送不到網頁」，v0.17 修的是「送到了，但貼錯地方」。

---

## 你會感覺到什麼

| 以前 | 現在 |
|---|---|
| 切過去要先點一下輸入框才能貼 | 切過去直接 `⌘V`，游標已經在輸入框末尾 |
| 被省資源釋放過、切回來重建的帳號，`⌘V` 完全沒反應 | 重建後一樣直接貼得上 |
| 貼上的字有時跑到草稿最前面 | 一定接在文字後面 |
| 選字複製只能靠右鍵（`⌘C` 沒反應） | `⌘C` / `⌘V` / `⌘X` / `⌘A` / `⌘Z` / `⇧⌘Z` 全部可用 |

功能上沒有新增按鈕，也沒有新的操作要學——就是原本該會動的東西會動了。

---

## 之前為什麼貼不上

用一張圖講完：

```
你按 ⌘V
   ↓
macOS 透過「編輯」選單把它變成 paste:        ← v0.16 補上這張選單
   ↓
paste: 沿回應鏈找到網頁                        ← v0.16 修好這一步
   ↓
WebKit 只貼給「有游標焦點」的元素
   ↓
但切帳號 / 頁面重繪後，焦點會退回 <body>      ← v0.17 修的是這一層
   ↓
內容被插進不可編輯的 <body> ＝ 看起來什麼都沒發生
```

關鍵在最後一行：`paste:` **有執行、沒報錯**，所以從外面完全看不出失敗，只覺得「貼不上」。

而且實測發現：即使切過去的那一刻焦點是好的，Muse 把對話載完、重畫一次之後焦點**又**會掉。所以光在切換時補一次焦點是靠運氣——這就是為什麼 v0.16 之後你還是會遇到。

---

## 這次怎麼修的（兩個保險）

**第一層：切過去就把游標放回輸入框。**
切換帳號、以及頁面載入完成時各排一次。判斷很保守：

- 焦點已經在輸入框 → 一個字都不動（不會打斷你打到一半的草稿）
- 你已經點在別的元素上（正在選字、看圖片）→ 不搶
- 還沒畫出輸入框（沒登入、還在載入）→ 3 秒後再試，最多三次
- 都沒有 → 聚焦，游標放文字末尾，而且**不會讓頁面滾動跳走**

**第二層：按 `⌘V` 的當下自己再確認一次落點。**
補焦點再怎麼勤，頁面重繪隨時會吃掉它。所以「貼上」這個動作改成：按下時先看游標在不在輸入框，不在就先放回去，再貼。

好處是焦點本來就正確時**零延遲**（不會每次貼上都多等一下），只有剛好被修過焦點時才等 0.5 秒——那是 WebKit 內部狀態跟上所需的時間，短於這個值反而會貼到舊位置。

## 10 秒自檢

1. 在 1 號對話框選一段字，按 `⌘C`（**不要用右鍵**，右鍵那條路本來就是好的，測不出問題）
2. 按 `⇧⌘2` 切到 2 號
3. 不要點任何地方，直接 `⌘V`

字應該直接出現在 2 號的輸入框裡。若沒有，把 `~/Library/Application Support/MuseDock/accounts.json` 旁邊的日誌抓下來，裡面會有 `PASTE_ROUTE ... focus=already|focused` 這一行，能看出當時焦點在哪。

## 一個小開關

不喜歡切過去游標就跳到輸入框的話：

```bash
MUSE_NO_AUTOFOCUS=1 open -a MuseDock
```

關掉之後，**貼上本身仍然不會失效**——只是你得先點一下輸入框。這是「自動化」與「不要自作聰明」之間的分界，留給你決定。

---

## 還是會遇到的情況（先說清楚，不是 bug）

| 情況 | 行為 | 原因 |
|---|---|---|
| 側邊欄「改名」的原生輸入框裡貼 | 正常貼在原生框 | 那是 App 自己的控件，不走網頁 |
| 帳號還沒登入、頁面沒有輸入框 | `⌘V` 最多等 1.5 秒才放行 | 沒有落點可貼，等太久更難用 |
| 貼的是圖片／富文本 | 與手動點輸入框後貼完全一致 | 內容仍交給 WebKit 原生處理，我們只負責把游標放對 |

## 升級

```bash
cd MuseDock && git pull && ./build.sh
```

`accounts.json` 格式沒有變動，**不需要重新登入**，頭像快取也不用重抓。

想退回上一版：換回 v0.16 的 `.app` 即可，資料不受影響。
