# MuseDock v0.19 更新說明

**一句話：同一個 Chrome Profile 不會再被匯入成兩張卡片——第二次匯入前會先問你。**

---

## 一、匯入前先問「這個已經匯入過了」

重複帳號偵測（卡片上的 ⚠︎）以前要等頁面載完、比對過左側對話列表才看得出來。
問題是那時候卡片**已經多了一張**，而多出來的那張不會自己消失——刪錯一張就等於丟掉那個帳號的登入。

現在在按下去的那一刻就會問：

| 你要做的事 | 會看到的提示 |
|---|---|
| 把「Profile 11」再匯入到**同一個**帳號 | 「『Grass』已經匯入過」→「重新匯入」／「取消」 |
| 把「Profile 11」匯入到**另一個**帳號 | 「這個 Profile 已經匯入過了」→「仍要新增」／「取消」 |
| 匯入一個**沒匯入過**的 Profile | 不問，直接匯入（跟以前一樣） |

第二種情況刻意保留「仍要新增」，不是擋你——cookie 過期後重新匯入同一個 Profile 是正常操作。

> 只在「從 Chrome 匯入」這條路徑生效。從 `cookies.txt` 檔案匯入沒有來源目錄可比較，行為不變。

---

## 二、匯入前可以先看一眼

不想開 GUI 也可以查：

```bash
MUSE_CHROME_LIST=1 ./MuseDock.app/Contents/MacOS/MuseDock
```

每一行後面多一個欄位：

```
  Profile 11 | Grass  | sulipa888@gmail.com     | cookies=13 | last=11/26 19:21 | already=3
  Profile 2  | sulipa | liangshienlin@gmail.com | cookies=12 | last=11/26 19:21 | already=-
```

`already=3` = 這個 Profile 已經匯入成第 3 號帳號；`already=-` = 還沒匯入過。
這個指令是純查詢，不會改你的資料。

## 三、順手修的兩個小地方

這兩項是「每週自動檢查流程」預演時發現的，不影響日常使用，但會讓自動檢查誤判：

1. **熱鍵叫回視窗**：在別的 App 前面按 `⇧⌘n`，以前可能只換了內容、視窗還留在後面；
   macOS 14 之後系統改了「誰可以把視窗叫到前面」的規則，這版跟上新規則。
2. **內部自測跑完會自己結束**：以前要外部強制關掉，現在跑完就退出，結果直接從退出碼看得到。

## 四、升級

```bash
./tools/update.sh
```

`accounts.json` 格式沒變，**不需要重新登入**，頭像快取也不用重抓。

想退回上一版：

```bash
./tools/rollback.sh          # 回到 v0.18
./tools/rollback.sh main     # 後悔了，回到最新
```

---

## 五、這版沒做的事（先講清楚，免得以為是 bug）

- **熱鍵還是不能自訂**：固定 `⇧⌘1–9`，與別的 App 衝突時只能改用「帳號」選單或側邊欄卡片。
- **`cookies.txt` 匯入仍可能產生重複**：那條路徑沒有來源目錄可比較，只能等 ⚠︎。
- **手改 `accounts.json` 把 `storeID` 改成不是 UUID 的字串，啟動會直接崩**：
  不影響正常使用，已列進待辦。
- **介面完全沒動**：這版所有改動都在看不到的地方。

完整技術說明見 [`CHANGELOG-v0.19.md`](CHANGELOG-v0.19.md)。
